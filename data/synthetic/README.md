# Directed robustness set

**64 rows** built from the gaps in the coverage matrix
(`../../docs/09-coverage-and-blind-set.md`), not at random. One row per gap between what the
client's catalogs contain and what the 15-row MTO exercises.

| File | What it is |
|---|---|
| `MTO_sintetico.xlsx` | The 64 rows in the same 6-column format as the real MTO, including the `MATERIAL` column trap |
| `expectativas.csv` | Gap covered and expected behavior per row |
| `MTO_sugerencias.xlsx` | Test bed for **several** vocabularies, not just finishes. Generated by `pnpm run mto:synthetic`. `MTO` sheet with extra columns (`NOMBRE`, `NORMA`, `ACABADO`) so each token lives in its own cell; `guia` sheet (the pipeline doesn't read it) says what to impute in each row. It is not gold |

## Two rules

1. **Generated from `reglas_tornilleria.md`, not from the given MTO.** It covers what the blind set
   is going to explore, not what is already known to work.
2. **It does not run until day 4.** If used to iterate from day 2 onward, it stops measuring
   generalization and becomes a second training set. It is its own blind set.

The expectations were written **before the system existed**. It's the only way to ensure they are
not biased by whatever the system ends up doing.

## `MTO_sugerencias.xlsx` — imputing vocabulary

The real MTO mixes name, standard, quality, and finish in `DESCRIPCION`. This file **splits each
token into its own column** so several vocabularies' onboarding can be exercised without guessing the cell.

`MTO` sheet (the one the pipeline processes):

```
ITEM | DESCRIPCION | MATERIAL | MEDIDA | CANT. | UD | NOMBRE | NORMA | ACABADO
```

`MATERIAL` remains the trap from the real MTO: it is almost never the material, it's the quality. The ingest
concatenates all the text cells, so `NOMBRE` / `NORMA` / `ACABADO` end up in `sourceText`
just like `DESCRIPCION`. The token **is not duplicated** in the description.

`guia` sheet: item → vocabulary → token → whether it's editable today. The pipeline ignores it (it only reads
the first sheet with headers).

| Block | Column | Editable today | What is expected |
|---|---|---|---|
| finish | `ACABADO` | yes | P-12 → Sent to review; onboarding in `/vocabulario?attr=finish` |
| material | `MATERIAL` | yes | ASTM quality with no derivation → material onboarding |
| quality | `MATERIAL` (`GR 12H`) | no | outside §5; 45H is already decided and doesn't serve as a test bed |
| name | `NOMBRE` | no | `vis` already in §3; `bullone` outside the family |
| standard | `NORMA` | no | unknown family or ASME with no DIN→ISO equivalence |
| mix | `ACABADO` + `MATERIAL` | yes (both) | two onboardings in the same row |
| control | — | — | already covered, green queue |

```bash
pnpm run mto:synthetic          # regenerates the xlsx
```
